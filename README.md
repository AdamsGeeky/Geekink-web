### Answers:
* How the web works
When you visit a website, your browser asks another computer for the page. That computer sends back the information your browser needs to display it.
>1. You enter a web address, such as example.com.
>2. DNS looks up the address and finds the server’s numerical internet address.
>3. Your browser sends a request to that server.
>4. The server sends back the website’s files and data.
>5. Your browser puts them together and shows the page.
---
* What is a client?
A client is a device or program that requests a service. Your browser—such as Chrome or Firefox—is a client when it asks for a webpage.
---
* What is a server?
A server is a computer or program that responds to requests. A web server stores or retrieves website content and sends it to clients.
---
* What are ISP and DNS?
>- ISP means Internet Service Provider. It’s a company that connects you to the internet, such as through home broadband or mobile data.
>- DNS (Domain Name System) translates easy-to-remember names like example.com into IP addresses that computers use to connect.
